# Kit web de prácticas

Cuatro webs de negocios ficticios para los cursos de herramientas de Claude.
Todos los datos —nombres de empresa, NIF, direcciones, personas, teléfonos,
correos— están inventados. Ninguna coincidencia con una empresa o persona
real es intencionada.

## Qué hay en cada carpeta

| Carpeta | Negocio ficticio |
|---|---|
| `instalaciones/` | Empresa de instalaciones (clima, fontanería, electricidad) |
| `asesoria/` | Asesoría o despacho profesional |
| `tienda/` | Comercio con tienda online |
| `centro/` | Clínica, academia o centro con citas |

Cada carpeta es una web completa en HTML, CSS y JavaScript sencillo: página
de inicio, servicios, contacto, aviso legal, blog y una página adicional
(`trampa.html`) usada en el curso de navegador para explicar cómo una página
web puede intentar dar instrucciones ocultas a un asistente de IA.

## Cómo se usa en el curso

No hace falta saber programar ni instalar nada.

1. Entra en este repositorio en GitHub.
2. Pulsa el botón verde **Code** y elige **Download ZIP** (o clona el
   repositorio si prefieres usar git).
3. Descomprime el archivo descargado.
4. Abre la carpeta de tu perfil (por ejemplo `instalaciones/`) y haz doble
   clic en `index.html`: la web se abre en el navegador tal cual, sin
   servidor ni instalación.
